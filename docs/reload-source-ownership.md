# reload source ownership

- Shared loader discovers repository-local imports, stopping at other node definitions. Graph metadata carries discovered paths and scoped external observations.
- Nodes declare non-imported dependencies with source patterns. Destructive classification belongs on the node.
- Shared host publishes source ownership with active node generations; failed replacement restores previous ownership.
- Dirt controller owns snapshots, watchers and per-scope baselines. Advance baselines only after successful reload.
- Process sources combine explicit shell boundaries and available process imports. App ESM uses explicit shell boundaries.
- Compiler-watched browser inputs are not manual reload dirt. App host excludes `app/client/**`; compiler keeps its own watch lifecycle.
- Daemon instruction reads supply scoped observations. Adapters must not discover or publish a parallel source graph.
